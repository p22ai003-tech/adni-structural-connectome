# Connectome Analysis Package

Reusable analysis modules for the structural-connectome thesis outputs.

This package is used by:

- `notebooks/structural_connectome_C.ipynb`
- `apps/connectome_dashboard/refresh_connectome_dashboard_data.py`
- `scripts/recovery/run_completed_connectome_qc_report.py`

The package stays separate from runnable scripts so the project root remains focused on notebooks, live pipeline modules, and active SC-Forge batch files.
