## Status rules

| Status | Meaning |
|---|---|
| DONE | Acceptance test passed and an evidence artifact exists. |
| ACTIVE | Work is in progress now. |
| READY | Can start without another dependency. |
| QUEUED | Valid task, but a dependency must finish first. |
| BLOCKED | Work cannot proceed because a named external or technical condition is unmet. |
| INTERRUPTED | A started process ended without its required terminal attestation; preserve evidence and obtain explicit resolution before restart. |
| HUMAN GATE | No downstream irreversible or expensive action until the user approves. |
| HOLD | Deliberately deferred; not part of the current critical path. |
| SUPERSEDED | Retired by an explicit scope/design decision; retained for provenance but not counted as pending work. |

No item becomes DONE because code ran or a file exists. Its acceptance test must pass. Failed, null, and excluded results remain part of the evidence record.
